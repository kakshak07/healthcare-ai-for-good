# Contributing to Healthcare AI for Good

Thank you for your interest in contributing to healthcare AI for good!

## How to Contribute

### 1. Report Issues
Found a bug? Have an idea?
- Open an issue on GitHub
- Include clear description
- Provide reproducible steps

### 2. Code Contributions
- Fork the repository
- Create a feature branch: `git checkout -b feature/your-feature`
- Make your changes
- Add tests
- Submit a pull request

### 3. Documentation
- Improve docs
- Add examples
- Write tutorials
- Translate to other languages

### 4. Clinical Validation
- Help validate models on real data
- Conduct clinical trials
- Provide feedback from healthcare professionals

## Guidelines

- Follow PEP 8 style guide
- Write clear commit messages
- Add docstrings to all functions
- Include unit tests
- Update documentation

## Code of Conduct

- Be respectful and inclusive
- Focus on patient safety
- Prioritize healthcare equity
- No discriminatory content

## Recognition

Contributors will be recognized in:
- README.md
- GitHub contributors page
- Project announcements

Thank you for making healthcare better for everyone! ❤️
